Vérifier des entreprises à partir du SIRET

  1. Choisissez la table et la colonne contenant le SIRET.
  2. Cliquez sur Vérifier : chaque SIRET est interrogé dans la base Sirene.
  3. Cliquez sur Copier en tête d'une colonne, sélectionnez la première cellule de la colonne cible dans Grist et collez (Ctrl/Cmd + V).

Astuce : « comparer à… » sous chaque en-tête surligne les écarts avec une colonne existante.

Données : base Sirene de l'INSEE, via recherche-entreprises.api.gouv.fr ou portail-api.insee.fr. Les valeurs copiées suivent l'ordre choisi ci-dessus : triez votre vue Grist de la même façon avant de coller.
